# statecraft-blog

A modern full-stack blogging platform built to deeply explore React Context API, scalable frontend state management, authentication workflows, and PostgreSQL database architecture.

---

# Problem Statement

Most beginner blog applications focus only on displaying content and completing CRUD operations without helping developers truly understand how modern full-stack systems work internally.

As applications grow, managing shared state, authentication, user sessions, API communication, and database relationships becomes increasingly complex. Many developers rely heavily on tutorials and copy-paste solutions without fully understanding concepts such as global state management, backend architecture, and relational database design.

This project is being built to solve that learning gap through a real-world, production-style blogging platform.

---

# Purpose of the Project

The goal of this project is to deeply understand and practically implement:

- React Context API
- Global state management
- Authentication and authorization
- REST API architecture
- PostgreSQL relational database design
- Backend development with Node.js and Express
- Full-stack application structure
- Scalable project organization
- Real-world development workflows

Rather than copying tutorials, this project focuses on learning by building systems from the ground up and understanding the reasoning behind every architectural decision.

---

# Project Goals

- Build a complete blogging platform from scratch
- Understand how frontend and backend systems communicate
- Learn how global state is managed in real applications
- Design relational database structures using PostgreSQL
- Implement secure authentication workflows
- Practice clean and scalable code organization
- Gain confidence in building production-style applications
